Multi-agent systems use multiple specialized AI agents that collaborate to solve complex tasks. A supervisor agent typically orchestrates the workflow by routing tasks to the appropriate sub-agents. Common patterns include ReAct, where agents alternate between reasoning and acting, and self-reflection, where agents critique and revise their own outputs. Agents communicate through shared state or message passing. Each agent is given a set of tools it can call, such as web search, database queries, or code execution. Tool selection is a key challenge: agents must learn which tool is appropriate for each subtask. In production systems, tracing conversation IDs across microservices is essential for debugging failures. Latency accumulates across agent hops, so minimizing unnecessary calls is critical for performance.
